## What We Did

### Database Migration
- Created `021_friendships.sql` — bidirectional friend system table
- Fields: `requester_id`, `addressee_id`, `status` (pending/accepted/declined/blocked)
- Unique constraint to prevent duplicate requests, CHECK to prevent self-requests
- Indexes on requester/addressee + status for fast lookups

## What We Learned
- The `EXPO_PUBLIC_API_URL` base URL does NOT include `/api/` — all endpoint paths need the full `/api/logs/mine` format. Easy to miss when building new endpoints
- Mutual friends calculation is surprisingly cheap — one bulk query for all friends-of-friends, then set intersection in JS
- The `formatFeedCards` helper with bulk photo/companion/sports fetching avoids the N+1 trap that would've killed performance on the feed
- Metro bundler aggressively caches — after a repo move/re-clone, `--clear` flag is essential
