## What We Learned
- React Native does NOT support stacking multiple `<Modal>` components — if Modal A is open and you render Modal B inside it, Modal B won't show. Solution: hoist both modals to the same parent level and close A before opening B
- The 350ms delay between closing Settings and opening EditProfile is needed for the dismiss animation to complete before the new modal opens
- `useAuthStore().user.id` is the Supabase UUID — same value that feed cards return as `card.user.id` — so profile lookups should be consistent
