## What We Learned
- The polymorphic `SharedModal` approach pays off fast — once the shell exists, refactoring existing modals to use it removes ~200 lines each and guarantees consistency
- User strongly prefers UI feedback to match the app's design language (green glass, not yellow warnings)
- Inline search on the sports hub is much more natural than a separate "find your event" screen behind a button — the browse-by-sport acts as a fallback when there's no search query
