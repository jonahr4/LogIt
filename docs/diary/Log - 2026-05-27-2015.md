## What We Learned
- React Native `textShadow` looks boxy — better to layer a duplicate transparent Text element behind with green shadow for a smooth glow
- `presentationStyle="pageSheet"` on iOS shows white corners because the system renders a white background behind the rounded sheet — custom modal with `transparent` + overlay is cleaner
- `lazy: false` on React Navigation tabs eliminates first-visit jitter (screens pre-render on app load)
- Having a shared `PageHeader` component is critical — one change propagates everywhere, no more inconsistency drift
- Views with `backgroundColor` + large `borderRadius` + `shadowRadius` still show hard edges — shadow renders around the view bounds, not a soft diffuse glow
