## What We Learned
- **Polymorphic component patterns work great for modals** — having one shell with `children` and optional `stickyContent` makes it easy to keep visual consistency while allowing different content shapes
- **Profile needs curated content, not generated** — user rejected the activity heatmap but loved Top 4 and Highlights. The "pick your favorites" approach feels more personal than auto-generated charts
- User has strong opinions about spacing consistency — equal margins above/below elements, matching widths between modals, same padding values
